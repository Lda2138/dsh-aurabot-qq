# Aurabot QQ

面向 DeepSeek Harness 的 QQ 聊天插件，通过 OneBot v11 / SnowLuma 接入。此仓库是基于上游的独立修改版。

## 开发经验

[聊天代理开发经验与踩坑记录](docs/DEVELOPMENT-NOTES.md)：上下文、记忆、工具执行、投递回执、语音权限、测试和隐私发布。案例已匿名化。

## 功能

- QQ 私聊和群聊、人格、表情、心情、长期记忆与只读历史检索。
- 家庭群上下文、按来源区分事实和旧回应、日记送达状态、异常空回复恢复。
- 可选 TTS、翻唱、生图与本地接口；需要使用者自行安装并配置对应服务。
- 语音任务与真实发送回执持久化，未知回执不会自动重发。

## 语音权限

**语音仅允许发送到已配置的主人（包括共同主人）私聊，以及指定家庭群。**

普通好友和普通群一律使用文字，主人在普通群发起请求也不能改变范围。限制覆盖普通 TTS、自动语音、语音文件、翻唱与补发、原始 QQ 语音接口和嵌套转发。无法检查内容的转发引用也只允许发往上述范围。发送前会重新检查当前权限。

## 安装与配置

1. 准备 Node.js 24，以及支持插件的 DeepSeek Harness。
2. 将本仓库作为本地插件加载，参照 [使用手册](docs/USER-MANUAL.md) 配置 OneBot 网关。
3. 在本机面板填写机器人、主人、共同主人及家庭群；默认总开关关闭、试运行开启。
4. API 密钥、账号登录、Cookie、语音服务及音色均由使用者自行配置。

仓库不提供任何个人账号、聊天记录、记忆数据库、凭据、原始录音、个人音色 ID、参考音频或训练权重。不要把运行数据目录提交到 Git。
