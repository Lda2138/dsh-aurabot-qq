# Aurabot QQ

An independently modified DeepSeek Harness / OneBot QQ plugin, based on [the upstream project](https://github.com/aureth-labs/dsh-aurabot-qq).

Outgoing audio is restricted to configured owner/co-owner private chats and configured family groups. Other destinations use text, even if an owner requests audio there. TTS, song covers, retries, audio files and raw QQ actions share this restriction.

No personal account configuration, credentials, conversations, memories, recordings, cloned voice IDs or model weights are included. Configure integrations locally. Node.js 24 is recommended. Run `npm test` for synthetic offline tests. See the [Chinese README](README.md) and [third-party notices](THIRD-PARTY-NOTICES.md). MIT license.
