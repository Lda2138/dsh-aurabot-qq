# Aurabot 使用手册（给不懂技术的你）

> 大肥鱼的「家」在 DeepSeek Harness（下面简称 DSH）里，QQ 是她的手机。
> 所有设置都在 DSH 左侧栏「自动化任务」下面的 **Aurabot** 里。

人物小档案是可能过期的印象，当前明确纠正更可靠。单次情绪、句号或表情不应成为长期标签；说话的篇幅、标点和分条可以随语境变化，不要求每轮固定两条。提炼遇到失败会暂停该聊天的后续日期，其他聊天仍可继续，原始流水保留。

本机诊断接口 `/aurabot/api/conversation/replay` 可用历史系统提示与文字消息做对照预览，只返回模型文字，不创建会话、不执行工具、不发QQ，也不写入记忆或心情。该预览会产生模型用量；局部回放不等于完整长历史或真实QQ验收。

对照时可指定 `reasoningEffort`（如 `low`、`high`）及相同的 `maxTokens`（256–8192，默认2000）。显式档位不被模型支持时会报告失败，不自动换档；返回的 `ok` 还要求输出正常结束，仅代表生成完成。判断说得好不好仍需阅读原始回复，回放参数不会保存到聊天设置。

还可用 `model: {provider, model}` 选择宿主已配置的模型做同题对照；这只影响单次回放，不更改全局或QQ聊天的模型。

`/aurabot/api/conversation/context` 可按家人 `chatId` 只读导出当前插件资料，不调用模型；对照旧运行快照时可先冻结这份资料。它不包含宿主完整工具、附件和运行环境，不能当成完整请求。

维护接口定向重开家人会话时，会保留归档会话和记忆，并停止自动补回重开之前的本地聊天、跨窗口节选；之后新说的近况仍正常共享。普通断线恢复的最近聊天补载保持原行为。

## 一、第一次使用（大约 10 分钟）

### 聊天与旧画回顾

她可以只读翻查以前的作品记录，区分家人的原话、创作提示词和实际送达结果。问旧画内容时会先核对记录；没有看到原图时，不应把提示词当作实际画面。新图先保存成品，再交给QQ；未确认送达的成品会保留，不自动重复生成或补发。

真人问题遇到异常空正文会有限恢复；写成文字的工具调用不算已经执行。中途收到新消息时，续答只参考已经实际发出的部分，减少重复开头。家人聊天会核对当前意思、事实和明确意愿；模型仍可能理解不准确，核对服务不可用时保留原文并记日志。

第一次打开 Aurabot 会自动出现 **设置向导**，跟着走 5 步就行。以后想重新走，可以在「连接」标签点「重新走一遍设置向导」。如果升级前已连上 QQ 且机器人号核对通过，向导会显示「使用现有连接，进入面板」，点它即可保留当前设置并完成向导。

### 1. 你们的 QQ 号
- **机器人 QQ 号**：给大肥鱼用的号，**一定要用小号**。
- **你的 QQ 号（主人）**：操作电脑这些只听主人的。

> **家庭群**：「系统 → 权限 → 主人」里的「家庭群」填上只有家里人的群号。她在那里只听主人们的，权限和记忆都和私聊一样，但回话收着点，被叫到才一定回。
>
> **两位主人**：「权限」页的「主人」卡片里可以再填一位主人的 QQ 号和称呼（比如另一位家长）。她的权限和你完全一样；DSH 要授权、危险命令确认会在她自己的私聊里问。各种通知还是只发给你。

### 2. 准备 SnowLuma（让机器人号能上线的 QQ 网关）
> 已经有 QQ 机器人服务（NapCat、LLOneBot、Lagrange、Docker 里的 SnowLuma……），或者在 Linux / Docker 上跑 DSH？在这一步选 **「接我已有的 OneBot 机器人」**，填它的正向 WebSocket 地址（和 token，有的话）就行，下面 SnowLuma 的几步都不用做。插件只连接，不启动、不注入任何东西，连上后会先核对登录的是不是机器人号。

SnowLuma 的协议不允许别的程序替你下载安装，所以这一步要你自己来（只做一次）：
1. 点「打开下载页」，下载名字类似 `SnowLuma-v2.x.x-win-x64.zip` 的文件（**不带 lite** 的完整版）。
2. 解压到一个纯英文目录，推荐 `C:\Aurabot\snowluma`。解压后这个目录里应该能直接看到 `index.mjs`。
3. 填好目录后点「检查」，会显示「找到了 SnowLuma」。

### 3. 启动并同意协议
1. 点 **启动 SnowLuma**。它在后台运行，不会弹黑窗口。
2. 控制台密码由插件 **自动生成并保存**，你不用设，也不用记。
3. 面板里会显示 SnowLuma 的用户协议和隐私说明。读完后勾选「我已阅读并同意」，再点 **同意**。

> 如果你之前自己在 SnowLuma 控制台里设过密码，这里会提示「插件登不上」，点 **重置为自动密码** 就好。

### 4. 接入机器人号
1. 电脑上另开一个 QQ，登录机器人号，可以最小化。你的主号 QQ 照常开着，不用管。
2. 点 **接入机器人号**。Aurabot 只给登录机器人号的那个 QQ 进程接入，**你的主号永远不会被碰**。点「看看有哪些 QQ 进程」可以亲眼确认：主号那一行写着「不会碰」。
3. 等十几秒，看到「连上了：大肥鱼（机器人号）」就成功了。

### 5. 先试运行，再正式上线
1. 推荐选 **先试运行**：她会照常思考，但只把要说的话写进日志，**不会真的发出去**。
2. 用你的主号给机器人号发一句「在吗」，然后去「日志」标签看她本来要回什么。
3. 觉得没问题，就把右上角的 **试运行** 关掉，她就正式上线了。

- **QQ 会话放在哪**：默认在用户目录下的 Aurabot\qq-chats，想放到别的盘就在「连接」页填完整路径（比如 D:\Aurabot\qq-chats）。

## 二、日常怎么用

| 想做的事 | 去哪里 |
|---|---|
| 让她暂时别说话 | 关掉右上角的 **总开关** |
| 只看她想说什么、不真发 | 打开 **试运行** |
| 把她拉进一个群 | 先在 QQ 里拉机器人号进群，再去 **权限** 标签，把群号加进「群白名单」，保存 |
| 允许某个朋友私聊她 | **权限** → 私聊白名单，加上对方 QQ 号 |
| 改她的性格 | **人格** 标签：直接改文字，保存后下一句起生效 |
| 换一套人格 | **人格** 标签：选中一个，点「设为当前」 |
| 让她在群里话多一点或少一点 | **群聊** 标签：调「插话概率」，也可以只对某个群单独设置 |
| 在私聊里让她帮你操作电脑 | **权限** →「主人私聊的权限」选「完整」（默认就是） |
| 换声音 | **语音** 标签：选音色，点「生成」试听；也可以用「翻唱」页导入的 RVC 音色给语音条变声（说话和唱歌同一个声音） |
| 管理表情包 | **表情包** 标签：可以改名字、删除、上传新的 |
| 让她回顾今天并发家庭群 | **家庭日记** →「现在写一篇」 |
| 让她现在来找你 | **概览** 或 **主动搭话** →「现在就让她来找我」 |
| 看她和某个人聊了什么 | DSH 左侧栏的「Aurabot · QQ」工作区，点对应的会话 |
| 插一句话帮她回 | 在那个会话里直接打字，她这一轮的回复也会发到 QQ |

### 在 QQ 里直接管她

你（主人）在私聊或白名单群里发这些命令就行，别人发了不算。总开关关着时也能用。

| 命令 | 作用 |
|---|---|
| `/silent`（`/闭嘴`） | 在这个聊天里先不说话；`/silent 30` 是安静 30 分钟 |
| `/active`（`/说话`） | 解除闭嘴 |
| `/quiet` `/chatty` `/normal` | 这个群里：不插话 / 话多一点 / 恢复默认 |
| `/model`（`/模型`） | 看能用的模型；`/model 2` 或 `/model 名字` 换，`/model 默认` 跟随 DSH |
| `/status`（`/状态`） | 看她现在的状态 |
| `/diary`（`/日记`） | 写一篇当天经历日记发家庭群 |
| `/remember 内容`（`/记住`） | 让她记住一件事 |
| `/reset`（`/重开`） | 这个聊天重新开始 |
| `/off` `/on` | 关掉 / 打开总开关 |
| `/help` | 看全部命令 |

## 三、她会做的事

- **聊天**：短句、口语，想说的多会拆成几条，每条之间像真人一样停顿一下。
- **群聊**：被 @、有人回复她、或者提到「大肥鱼」「肥鱼」时会回，群聊安全刹车和闭嘴设置仍然生效。一个人 @ 或引用她时，她的第一条回复会引用那条消息并真正 @ 对方；多人同时找她时不猜要 @ 谁。其他时候偶尔插一句，也可能选择不说话。
- **家庭群聊天节奏**：两分钟连续回复达到 8 轮时，只提醒她说短一点、别重复，让她按新消息判断继续聊还是自然收尾；家人的消息仍交给她，不会因为达到次数突然不理人。普通群防刷屏及手动闭嘴设置照常生效。
- **漏收补回的时序**：补到的旧消息会按原发送时间补进历史背景，并带上后续已经发生的对话。她判断是否还有需要补答的问题或交代；已收尾的聊天可以保持安静，不会要求她追着旧表情再回一句。补收不当作当前新发言，也不打断正在生成的新回复。
- **看引用**：别人引用一条消息时，她会去查被引用的内容（谁说的、正文、几张图/表情），私聊和群聊都能看到；引用的是她自己以前说的话时会标成「你」。引用里的图片和表情包也会作为附件给她看（最多 2 张）。查不到时她会知道「这条引用没读到」，可以如实说没看到，不会装作看见了。

- **主人私聊问群里的情况（默认关）**：面板「聊天 → 主人私聊：群聊摘要」打开后，你在私聊里问「群里刚才在聊什么」，她会把最近 24 小时白名单群的聊天流水当成自己看到的见闻接着说，不会当成你发给她的消息；不常驻上下文、不写进记忆。可限定只取哪些群、每个群给几条（最多 30 条）。只在主人私聊且这句话提到群相关时触发。
- **在群里 @ 人**：她 @ 谁，对方会真的收到 QQ 的 @ 提醒。她按群名片和 QQ 昵称找人；对不上、或者群里有两个同名的，她就不 @，只把名字当普通文字发出去。注意：你手机上给好友设的**备注**她看不到。比如你备注叫「小明」、他在群里叫「Luna」，你说「去 @小明」她是找不到的，告诉她群名片或 QQ 号就行，对不上时她也会跟你说没 @ 到。
- **替你去别的群 / 私聊说话**：在和她的私聊里说「去 XX 群说一声……」「跟 XX 私聊说……」，她会过去说（对方要在白名单里）。下次那个群再有人找她时，她记得自己刚才在那里说过什么，能接上话。
- **交新朋友 / 进新群**：QQ 网关不能让她自己加好友、申请进群，所以她在群里或私聊遇到聊得来的人、或想进某个群时，会私聊问你：是谁、在哪认识的、为什么想加。你同意就在机器人号的 QQ 上搜号加一下（进群就邀请她或替她申请）；不想加就回「算了 号码」，30 天内她不会再提。加上后她会提醒你把对方放进白名单。私聊里问她「你想加哪些人」能看到还没处理的。每天默认最多问 3 次，在「权限」页的「想交新朋友 / 进新群」里改次数或关掉。
- **让她自己管白名单（默认关）**：在「权限」页打开「让ta自己管白名单」后，和谁私聊、进不进群、在哪个群说话都由她决定：有人成了她的好友，她会想想要不要和对方私聊、要不要偶尔主动找对方聊；私聊名单里已有的人，她也会想要不要主动找；有人邀请她进群，她自己决定去不去；进群后她先旁听一阵（默认 24 小时）再决定要不要开口；不想再理某个人或群，她也会自己移出。每次改动她都会私聊告诉你，你也随时可以在「白名单」里直接改。
- **交友圈（自己交朋友，默认关）**：在「权限」页打开「交友圈：自己交朋友」。想不想交朋友、和谁交都由她自己判断。活跃朋友（最近 14 天私聊找过她，或刚加上 3 天内，你不算）少于设定人数时，她会看一份最近常在群里 @ 她、回她的人的名单，挑一个真心想交的，或者谁都不挑；平时在群里聊着聊着想邀请谁也可以。插件只管几条上限：同一个群一周最多邀请一次，朋友够多了不再邀请，删过她的人不再邀请。她邀请过的人来加她会自动通过、放进私聊白名单，她会告诉你，再去打个招呼；之后偶尔主动找对方聊（走「主动搭话」）。加上几天后她会回顾和对方处得怎么样，不想继续就淡下来：不再主动找，对方来找照常回。被对方删了，她最多一小时内就会发现并告诉你；只拉黑不删的情况她分辨不出来。问她「你最近交了哪些朋友」能看到现在的交友圈。试运行时不会真的通过申请。
- **发文件**：在和她的私聊里说「把 XX 文件发给我」就行，她也能按你说的发给白名单里的人或群。她只能发 QQ 工作区（她平时写文件的地方）和你在「聊天」页「发文件」里额外加的目录中的文件；单个文件默认最大 50 MB；每次发了什么会写进日志。这个功能在「聊天」页可以关掉。
- **危险命令确认（可选，默认关）**：面板「聊天」页打开后，她在私聊里要执行删除根目录、格式化、关机、下载后直接执行这类终端命令之前，会先发 QQ 私聊问你；回复「确认」才执行，回复「取消」或 60 秒没回就拦下，她也会把实际要执行的命令原文如实告诉你。群聊和其他人的会话没有本地终端工具，不会碰到这个开关。
- **看图**：支持视觉的模型可以看别人发来的图片和表情包；转发给她的聊天记录（合并转发）她也能展开看。她画完图后，支持视觉的聊天模型也能收到图片附件；大图需要本机 ffmpeg 缩图，缩图或附件服务不可用时她会如实说没看到。面板里「让她画完自己看一眼」关掉、或「视觉能力」选「不支持」时，画完只回一句「画好了」，不会把图给她看。
- **生图构图**：可以让她画方图、竖图、横图或宽幅，也能在「生图」页设置默认构图。工具本次指定优先于默认值；没有指定且默认是「让她选择」时，沿用原来的图片尺寸。四档尺寸分别为 1024×1024、1024×1536、1536×1024、1536×864。自定义接口使用 `{size}` / `{width}` / `{height}` 才会跟随构图，写死的参数仍按接口配置发送；服务不支持尺寸时会如实报错。
- **Codex 订阅生图（实验性）**：在「生图」页选择该接法并登录 ChatGPT，再保存配置。它使用非公开图片端点，可用性、支持的模型和额度由账号、工作区及服务端决定；不是公开 API 兼容性承诺。令牌单独保存在插件数据目录 `codex-auth.json`，不会放进配置或返回面板。登录使用本机 1455 回调；端口被占用时可粘贴完整回调地址，取消 / 超时 / 卸载会关闭本次登录。退出会删除插件保存的登录信息。该接法将所选构图作为提示词引导，实际尺寸由服务端选择，不保证严格比例。
- **用自己画的图**：画完会告诉她一个「画作编号」（#1 是最新那张）。想拿它换 QQ 头像，说「用画作 #1 换头像」；想收进表情库，说「把画作 #1 存成表情」。编号只在本聊天有效，重启后会重新算（画作文件一直都在）。
- **存刚收到的表情 / 图片**：主人说「存一下刚才的表情」时，她会从本聊天最近收到的图片中取图。每个聊天保留最近 6 张的短期引用，重启后可以恢复；有效期从收到时起算 30 分钟，重启不会延长。图片来源本身已经失效时，需要重新发图。
- **查看自己的 QQ 资料**：主人在 QQ 私聊里提到她的昵称、个性签名或头像时，她可以主动查询当前资料。例如问「你现在叫什么」「签名是什么」「喜欢现在的头像吗」。讨论头像画面时，会把实际图片作为附件提供给当前聊天模型，并附辅助描述；模型不支持看图或查询失败时会如实说明。查询仅限主人私聊，与修改资料的权限分别判断；查询本身不会发图或修改资料。
- **发送自己的当前头像**：主人在 QQ 私聊中说「把现在头像发出来」「发你的头像给我」时，她会用 `qq_send_avatar` 直接发送当前头像图片，无需先识图。试运行不真实发送；网关未确认时不会报告成功。关闭「改资料」模块后，查询和发送头像工具都会撤销。
- **换自己的头像**：私聊里说「用刚才那张图换头像」（你刚发的图），或者画完图说「用画作 #1 换头像」都行。图太大会自动缩到 640 以内再交给网关；缩不了或网关不接受时会如实说明，不会假装换好了。
- **戳一戳**：戳她会有反应，偶尔还会戳回来。
- **语音**：心情到了会发语音条；别人发的语音她会先转成文字再听。想让她说话也用「翻唱」里导入的音色，在面板「语音」页开「语音条变声（用翻唱音色）」选一个音色（翻唱环境要先装好；变声失败会用 TTS 原声，不影响发送）。
- **语音表达**：Breeze 会结合本句情境、她选的语气和家人确认的表达偏好来念。语音页可设置「开口前停顿」，默认给合成后的音频补半秒静音；这也适用于本地 TTS 和变声后的语音。
- **更新时正在合成语音**：普通语音会保存任务与成品，重载后接续尚未提交的语音；拿不到明确回执时不自动重复发送。接续仍检查开关、静音和原会话权限，超过10分钟的旧语音停止自动发送。试听、预览和语音测试不进入自动接续队列。
- **Breeze 暂时不可用**：默认将这句话改发文字，不突然切成 Windows 机械音。在语音页可选择尝试 edge 作为备用（需安装语音组件），备用也失败时仍改发文字。正常 Breeze 的音色、语速和开口前停顿不受影响。
- **记住交代的事**：家人说「跟你交代点事……记清了，千万不要忘了」，也能即时保存。尚未办完的嘱咐会在记忆列表标为「待办」，保留交代者、原时间条件，并在家人聊天和主动搭话时提醒她判断是否该办；没有明确日期就不编一个。家人明确确认完成或取消后，再更新状态，仅口头答应或把请求发出去不算完成。
- **发送与后续聊天**：截图、视频、翻唱、照片、文件和卡片等在网关确认成功后记入聊天记录；她之后能知道刚发过什么，截图会附来源和画面参考备注。部分发送失败只记成功内容。私聊提示需要先加好友时暂停当天重复尝试，另一位可达主人会收到一次提醒，收到对方消息或重新加好友后恢复。已识别限速的群会合并文字气泡、排队发送；超时等结果不确定的消息不盲目重发。
- **家庭群参与与记忆**：「家人聊天共享近况」默认开启，两位主人的私聊和指定家庭群双向带上最近 24 小时的近况，每轮最多约 300 字，标明时间、来源和说话人，只在相关时自然使用。面板可关闭临时近况共享，已经保存的长期记忆仍保留。家人明确说「请你记住」「帮我记一下」「记下来」会即时保存；称呼或表达偏好会在家人聊天中常驻。关联 QQ 的 DSH 会话里直接输入记忆要求，也会保存并标注为本机主人输入，不冒充正在查看的另一位家人。家庭群默认安静 75 分钟尝试开启话题，每天最多成功发言 5 次；沉默、失败不扣次数，但至少隔 20 分钟再试。普通群和外人的私聊不注入这些家人偏好和共享近况。
- **私人自拍**：允许使用生图工具不等于她必须发自己的照片。两位主人权限相同，她会根据关系、记忆、当时意愿以及照片会被谁看到来决定；可以商量或自然拒绝。普通画图不需要自拍分享决定。「仅主人生图」开启时，普通朋友仍不能请求生成或重发自拍。新自拍需要模型明确选择分享，旧自拍由 `qq_share_self_photo` 在当前聊天重新决定；已识别的自拍不能直接借图片链接或发文件绕过。没有设置固定长相时，只能按人设生成，不能保证每次同一张脸。
- **表情包**：会自己收藏群里看到的表情包（普通照片不收），并给每张起个名字。表情的名字和标签能在面板「表情包」页直接改（鼠标移到表情上，点名字或标签，改完点别处就保存）。QQ 表情商店里的商城表情会按原样发，动画由 QQ 自己播。在「表情包」页把总开关关掉，她就一张都不发了。
- **怎么偷表情（三种模式）**：面板「表情包 → 怎么偷」里选。「全都偷」是默认，看到就收；「她挑」只把表情记下来、给她一句轻提示，她喜欢才凭编号收；「只听主人的」只在主人私聊、或这一轮只有主人说话时才提示她收，有别人在场时她不能自己收，要主人发话。两种新模式下，表情会暂存 30 分钟（重启不丢），她可以用 `qq_collect_sticker` 按编号收，也能收自己刚画的图。
- **QQ 小黄脸**：她会在文字里夹 QQ 自带的系统表情（/捂脸 /斜眼笑 /吃瓜 这种），和文字在同一条消息里；别人发来的小黄脸她也认得是哪个。不想要就在「表情包」页关掉「夹 QQ 小黄脸」。
- **家庭日记**：挑上次分享后新增的一两件真实小事，直接发到系统权限中配置的家庭群。聊天、画图、唱歌、浏览都可取材，由她判断何时想分享，不再按每天次数和时间段自动发空间。没有新经历就跳过，素材少可以短写；发送前检查是否重复、是否添了没有依据的情节。支持不发群的预览、手动写一篇。总开关、日记开关、静音和试运行继续生效，成功送达才写日记记忆。明确要求发空间仍可使用独立工具，可见范围在本页单独设置。
- **空间互动**：有人评论她的说说会回（接着回她也会接着聊）；逛好友动态时偶尔点赞、评一句（在「空间日记」页打开）。
- **刷 B 站**：在「B站」页打开后，她会定时刷几个视频，看到好玩的私聊分享给你，也会自己发评论、回别人；你在 QQ 里发 B 站链接她也能看。
- **B 站看画面和截图**：在「B站」页打开「让她看画面」（默认关闭），安装 ffmpeg 并使用支持图片的模型。每个视频抽 2～12 帧，画面描述会和字幕、简介、热评一起交给她阅读；缺少 ffmpeg、模型明确不支持图片、取流或视觉调用失败时继续读文字。抽到的图片存在本机截图库，默认保留最近 300 张，可以在面板预览、删除、调整上限。QQ 聊天里说「有哪些截图」「发张刚才那个视频的截图」，她会按标题或画面备注挑选，发到当前会话。定时刷完默认有 35% 概率向主人私聊发一张，调成 0 就不自动发；试运行不会实际发送，也不会报告已经发送。
- **人声分离模型下不动**：安装会自动换国内镜像、断点续传；还不行就照面板「翻唱」页给的地址用浏览器下好，拖进「音色模型」框。
- **本地接口**：想用自己的 GPT-SoVITS、SD WebUI、自己训练的音色？在「本地接口」页生成模板，照注释改或者「复制给 DSH 的话」让 DSH 改，打开开关就行。
- **翻唱**：用你导入的音色唱歌，做好发语音条。在「翻唱」页一键安装、导入音色；QQ 里跟她说想听什么，或者发 `/sing 歌名`。做好了却没发出去（插件重载、网关出问题）时会留在「待补发」里，你在面板点「补发」，或者在 QQ 里让她补发；同一首歌再点一次也会直接补发那份成品，不重做。
- **主动搭话**：有到期的联系人时，她先选择找哪位家人、白名单朋友或家庭群，也可以等等；随后在对应聊天里结合真实记忆决定说什么。成功送达才新增次数，沉默和失败分别退避。家庭群默认最长隔 75 分钟考虑一次、每日最多实际发言 5 次，重启保留活动时间；普通群不进入主动候选。
- **主动关心家人**：选择时带上已配置的家庭身份、各位家人最近可见发言及近期主动送达时间；称呼留空也保留「妈妈」等身份。发言时间只算该家人本人，机器人或其他人发消息不会重置。只回看最近 48 小时，未知时间不猜，关闭家庭近况互通时按当前窗口提供。可以在家庭群自然关心话少的家人、偶尔 @ 对方，也可以安静；刚联系过未回复时给对方空间，没有每日必须完成的次数。群聊送达不代表特定家人已读。选择失败按请求异常、超时、格式或目标错误记录分类并退避，不记录模型原文。
- 好友检查使用实际 OneBot 客户端的连接状态；尚未查明好友关系时显示未知，不把「允许尝试私聊」当作已核实可达，也不把好友关系当作已送达。
- **普通群少说话**：在「系统 → 群聊」开启后，只有 @ 她、引用她或明确叫到唤醒词的消息才交给模型。普通群的日常消息在本地缓存，后续被叫到时能接上；家庭群仍由她自主判断。
- **偶尔偷表情**：普通群的自动收集与聊天分开，本地判断间隔和额度后才下载，默认至少隔 30 分钟、每天最多 8 张；重复或下载失败短暂退避。已有具体 QQ 说明时先用作名字，视觉命名与导入、批量补名共用每小时 4 次、每天 16 次预算，失败也占一次。额度用完继续留图，之后可手动整理；无需为了收表情让主模型一直看群。
- **记忆**：每天整理两次（默认 4 点和 16 点），把聊天提炼成长期记忆、相处经验，还会慢慢学会你们的说话方式。这些关于人和群的内容都在面板「人物记忆」页，能看也能改；开关和调参在「心情与记忆」页。这里可以把「自动记忆容量」从默认的 3000 条调高，最多 100000 条：聊天提炼、经历和日记按各自配额分配；手动记忆和分档事实不受此限制。提高容量不会关闭已有的过期和压缩规则。
- **家庭记忆与联想**：在“系统 → 权限”分别设置家庭身份和实际称呼，称呼留空仍可让她去问。爸妈私聊与家庭群按人物、话题和时间共享事实、日常经历及梗概；匹配使用中文分词后的完整词，普通短词不能单独触发旧事；一个较长实词、记录中的专名或两个有意义的词才建立话题关联，明确追问家人的事情可以按人物与话题查询。自己的浏览、评论、日记及发图只在明确问起自身经历时召回。引用和媒体说明不参与检索，自动注入不增加命中次数，家庭排序也不再采用历史命中强化。本轮原话和本窗口最近 15 分钟的原话不再作为旧记忆召回。同一条记忆及其原话来源在同一会话 30 分钟内不反复提醒，换说法或短暂换题不重置；明确追问、内容更新或间隔到期后仍可再次想起。原话、她的承诺、实际结果和印象会分开标注，更正优先；忘记的来源不再进入整理和召回。家庭整理、家庭梗概和旧记录回补分别有独立额度，默认每天 24、8、24 批，均可在“心情与记忆”页调整。梗概用于概括，具体事情仍可从保留原话中检索。
- **长期提炼与日期提醒**：普通问候、早晚安、刚醒或吃没吃饭留在原聊天流水，不再自动提炼成长期事实；健康状况、重要计划、关系、偏好和嘱咐仍可保留。家人明确交代日期提醒时，可以保存单次、每年或每 N 天的周期；日期和周期以原话为准。主动搭话会查看今天、明天的日期候选，遵守清醒时间、静音及每日额度，沉默或失败不记送达。现有相恋日期配合明确的“以后注意纪念日”嘱咐可用于周年候选，普通嘱咐不会被擅自设成每 100 天。电脑或 DSH 关闭时不能发，错过的历史日期不补发；提醒是主动选择的话题素材，实际自然表达仍需真实聊天验收。
- **自动补表情与连发合并**：主人谈心、连续发长句时暂停自动补图；每个聊天十分钟最多自动补两张，模型自己写出的表情仍按场合决定。表情包找不到但名字是 QQ 小黄脸时按系统表情发送。新配置的私聊合并等待默认 5 秒，既有设置可在聊天页调整。主动联系前会查询好友关系，不在好友列表中的私聊先跳过。
- **短期记录与感受**：短期记录按原聊时间失效，并保留说话人和来源。同一组人类证据在同一会话只提醒一次，重新整理或助手新增回应不会让旧话再次提醒；新陈述、明确更正和换话题优先。助手旧回应和感受分别留存供查询，真实对话及已做事情的记录照常保留。新轮次会撤下旧派生摘要。心情的负面判断需要本轮真实人类消息作为依据；这能核对原话来源，情绪与意图的理解仍由模型完成。
- **家庭近况共享去重**：已共享的时间范围按目标会话保存，重启后继续使用；新建会话可重新了解近况。新轮次会撤下旧派生共享节选，原始聊天仍可查询。共享中的“你当时回应”是历史记录，当前更正、换话题和系统行为反馈要重新理解。
- **换会话后的衔接**：新会话首次接收输入时，自动补本聊天最近约 20 条本地记录，含她自己的回应及时间，跳过已遗忘记录和本轮消息。补入完成状态持久保存，普通重启不会向连续会话重复补历史。聊天页“通过 QQ 补充新会话记录”是本地没有可补记录时的额外选项，默认关闭。

### 想让她多会点什么？（「模块」分组）

更多功能可以在面板「模块市场」安装，每个模块的说明在模块库里。

她的每项本事都是一个**模块**，在「已安装」页里：

- **不想要某项本事**：把那一行的开关关掉。比如不想让她刷 B 站，关掉「B站」，她就不会刷，也不会答应别人去看视频。
- **想改某项本事**：点那一行的「复制一份来改」，再点「复制给 DSH 的话」，粘给 DSH，写上你想怎么改（比如「空间日记写短一点，多用颜文字」）。DSH 改完保存，几秒内就生效。
- **想让她学会新本事**：在「新建一个模块」里起个英文名（比如 weather），点「新建」，把自动复制好的话粘给 DSH，写上你想要什么（比如「群里有人问天气，就去查一下告诉他」）。
- **先试试再上线**：「已安装」页最下面的「模拟测试」能假装发一句话、调一个工具，看模块会怎么反应，发出去的东西只显示在面板上，不会真发到 QQ。
- **改坏了**：那一行会显示红色的报错；你改的内置模块坏了会先自动用回原来的。实在不行就打开「安全模式」，你写的东西全部不加载，她恢复原样。
- 你写的东西放在 `%USERPROFILE%\.dsh\plugins-data\aurabot\modules\`，**升级插件不会动它们**。

## 四、出问题先看这里

> 换电脑：面板「系统 → 备份」点「立即备份」，把生成的文件拷到新电脑。新电脑装好 DSH 和 Aurabot 后，把文件拖到同一页（首次设置的向导里也有入口），重启 DSH 后会自动换上设置和数据、重新下载市场模块、放回 QQ 会话。备份里有账号凭证，别发给别人；DSH 自己的设置、QQ 网关登录和抖音、小黑盒的浏览器登录要重新弄。

> 装不上、报错了：先看面板「日志」里的报错和插件版本号；也可以扫 [README](../README.md#联系我们) 里的二维码加 QQ 交流群问，或在 GitHub 仓库开 issue（带上日志和版本号会快很多）。

| 现象 | 怎么办 |
|---|---|
| 她完全不回消息 | 1. 右上角总开关开了吗？试运行关了吗？ 2. 去「连接」看「QQ 网关」是不是「已连上」。 3. 对方在白名单里吗？ 4. 看「日志」标签有没有红字。 |
| 「QQ 网关」一直连不上 | 机器人号的 QQ 开着吗？QQ 重启过的话，去「连接」点「接入机器人号」。 |
| 「接入机器人号」说找不到 | 确认机器人号的 QQ 已经登录完成，等十几秒再点一次。 |
| 重启 DSH 后有一阵发不出消息 | 一般不用管。网关暂时连不上时会自动等几秒重试；上一个 SnowLuma 还没退干净时，会先等它释放端口，或者直接接着用它。刚连上那一会儿收到的消息也会补上。日志里看到「网关暂时连不上，…后重试」是正常的；一直重试失败再看上面那行。 |
| 她说 @ 了人，对方却没收到提醒 | 她只认群名片和 QQ 昵称，认不出你手机上给好友设的备注。告诉她对方的群名片或 QQ 号再让她 @ 一次。 |
| 群里她不说话 | 群号在「群白名单」里吗？试试 @ 她。 |
| 某个功能的标签页不见了 | 去「已安装」页看看对应的模块是不是关了。 |
| 翻唱说「读不了某个模型文件」 | 多半是杀毒软件（360、火绒、Defender）拦住了。把翻唱目录（比如 `E:\Aurabot\rvc`）加进杀毒软件的信任区；还不行就删掉提示里那个文件，在「翻唱」页重新下载。 |
| 装了自己写的模块后她不对劲 | 「已安装」页打开「安全模式」，你写的模块全部不加载。恢复正常就说明是那个模块的问题，看它那一行的报错。 |
| 语音发不出来 | 会自动改发文字。想要更好听的声音，在「语音」标签点「安装 edge-tts」。 |
| 回复很慢 | 「模型」标签里把思考强度选「低」；也取决于模型服务本身的速度。 |
| DSH 启动时报「Web authentication failed」 | 这是 DSH 自己的问题（本机登录 Cookie 攒太多）。关掉 DSH，删除 `%APPDATA%\@deepseek-ai\dsh-desktop\Network\Cookies` 里 127.0.0.1 的旧 Cookie 后重开即可；或者把报告发给我处理。 |
| 桌宠明明在跑，面板却一直显示「离线」 | 先看 DSH 桌面端的「浏览器访问」开关开没开：它关着时，桌宠客户端发出的所有请求（包括心跳）都会被 DSH 当成普通浏览器请求拦下（一律 403），在线状态就永远登记不上——桌宠程序本身没坏。把开关打开，桌宠下一次心跳（半分钟内）就会自动上线。 |

## 五、关于账号安全

- 机器人一定要用小号。用 SnowLuma 这类非官方工具有被腾讯限制或封号的风险，主号千万别拿来当机器人。
- SnowLuma 只给机器人号注入，你的主号进程永远不会被碰。
- 群聊里的大肥鱼没有任何操作电脑的能力；只有和你私聊时，在「完整」权限下才可以。

## 六、桌宠：把「大肥鱼」请到桌面上（小白跟做版）

1.2.0 起桌宠是社区模块：先在面板「模块市场」点安装，「桌宠」页才会出现。

桌宠是一个会待在你屏幕角落的小「大肥鱼」：她主动搭话会冒气泡，你也可以点她聊天。
不用懂任何技术，全程点按钮就行。

### 第 1 步：打开桌宠页面

打开机器人面板 → 顶部点「表达」→ 点「桌宠」。

### 第 2 步：点三个按钮（按顺序）

1. 点 **「下载 / 生成客户端」**——这一步把桌宠程序生成到数据目录，几秒就好。
2. 点 **「安装 Electron」**——桌宠的"引擎"，约 100 多 MB，走国内镜像，**1~3 分钟**，
   期间按钮可能没反应，等提示出现再动。
   - 这一步**不需要你装过 Node、npm 或任何编程环境**：有条件就用 npm 装，
     没有就自动直接下载官方压缩包解开，全自动判断。
3. 点 **「启动桌宠」**——桌面上出现大肥鱼就成功了！
4. （可选）想让她开机就在，把 DSH 设置成开机自启，再开桌宠页里的对应开关。

> 三个按钮都灰着或点了没反应？重启一下 DSH 再试。

### 第 3 步：平时怎么用

- **拖拽**：按住她可以甩到屏幕任意位置，会自己稳住。
- **聊天**：左键点她。
- **退出**：任务栏右下角托盘里有她的图标，右键退出；或回面板点「停止桌宠」。
- 她的心跳（在线状态）在面板「桌宠」页能看到；「主动搭话走桌宠」开关决定她搭话是冒气泡还是发 QQ。

### 「安装 Electron」失败怎么办（手动安装，进阶可选）

自动安装一般不会失败；npm 那条路失败时插件会**自动改用 zip 直装**，不用再点第二次。
如果反复失败（断网、杀软死拦），可以先试试把面板「桌宠」页的「Electron 镜像」换成别的地址；
还不行就手动来：

1. 用浏览器打开这个地址（整行复制）：
   `https://npmmirror.com/mirrors/electron/45.1.0/electron-v45.1.0-win32-x64.zip`
   （如果你的电脑是 ARM 芯片，把 `x64` 换成 `arm64`。）
2. 下载得到一个 zip 文件，**右键 → 全部解压**，解压到任意位置。
3. 打开文件夹：按 `Win + R`，输入
   `%USERPROFILE%\.dsh\plugins-data\aurabot\modules-data\pet\app` 回车。
4. 在里面进入 `node_modules` 文件夹（没有就新建一个，名字原样），把解压出来的文件夹
   改名为 `electron`，整个拖进去。
5. 回面板点「启动桌宠」。

> 前提：第 2 步的「下载 / 生成客户端」至少点过一次（`app` 文件夹才存在）。



翻唱选段：选择「演唱段优先」时，短片段会参考可用的歌词时间避开长间奏；歌词缺失时才使用全曲约30%的位置。歌词时间是选段估计，不能保证每秒都有人声。调整人声或伴奏音量后会重新制作，不复用旧混音。

翻唱账本：每首歌的排队、正在做、做过和「做成没发出去」都记在数据目录的 `song-jobs.json`。插件重载或重启后会把没走完的转成「待补发」，但不会自动补发——补发前会重新核对翻唱开关、白名单和原来的目标，拿到网关回执才算成功。只有记录、成品已被清掉的条目，补发时会照原样重做。同一首歌再点一次时，6 小时内做好的待补发成品会直接补发，不重新分离和换声。点歌时说的时间是按这台机器最近的实测说的，没有实测就不承诺具体分钟。


## 空闲创作与自己的余额

在「主动搭话」页的「空闲创作与自己的余额」卡片单独保存，立即生效。开启后，ta在配置的醒着时间、聊天空闲时自行选择画画、翻唱或休息；作品发到「系统→权限」指定的家庭群。普通群不会自动发作品。不要求每天创作，也不会把排队或失败写成已经完成。

聊天余额使用当前默认DeepSeek官方API账户或DeepSeek登录账户对应通道；余额分币种、带查询时间。画图目前接XHY账户，需要在XHY个人中心创建s2o- OpenAPI密钥，填写到本机卡片中；普通生图Key不能替代查询密钥。查询失败显示未知，不能解读成没钱或有钱。每15分钟刷新，超过30分钟标过时，家人聊天里ta也可以主动调用余额查询工具。低余额提醒线用于ta自己决定节省，不是每日强制支出预算。官方参考：https://docs.xhyapi.com/open-api/ 、https://api-docs.deepseek.com/api/get-user-balance/ 。

翻唱沿用原声库和本机制作队列，分离/换声本地执行；做决定仍会消耗聊天额度，音源费用取决于音乐服务。制作途中关掉自主创作、静音/移除家庭群或卸载模块后，不再向该群发送这份自主作品。
